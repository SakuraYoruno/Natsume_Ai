## 修复内容

### Bug 1：`/obs/vault/stats` 返回 500（ResponseValidationError）

**根因**：`host_brain/app/obs_routes.py` 的 `get_vault_stats()` 函数构建完 `recent_manifests` 列表后缺少 `return` 语句，FastAPI 收到 `None` 作为响应体，触发 `ResponseValidationError`。

**修复**：在 `obs_routes.py` 第 2293 行后添加：
```python
return VaultStatsResponse(
    total_manifests=total,
    active_count=active_count,
    undone_count=undone_count,
    gc_count=gc_count,
    reversible_count=reversible_count,
    reversible_rate=reversible_rate,
    recent_manifests=recent_manifests,
    timestamp=now,
)
```

### Bug 2：Semantic Recall `use_mock=true`，`chroma_port=8000`

**根因**：`dependencies.py` 的 `get_semantic_recaller()` 读取 `SEMANTIC_RECALL_USE_MOCK`（默认 `True`）和 `CHROMA_PORT`（默认 `8000`），但 `.env` 中只有 `CHROMA_ENDPOINT=http://127.0.0.1:8100`，没有独立的 `CHROMA_HOST`、`CHROMA_PORT` 和 `SEMANTIC_RECALL_USE_MOCK` 变量。

**修复**：在 `.env` 中添加：
```
CHROMA_HOST=127.0.0.1
CHROMA_PORT=8100
SEMANTIC_RECALL_USE_MOCK=false
```
