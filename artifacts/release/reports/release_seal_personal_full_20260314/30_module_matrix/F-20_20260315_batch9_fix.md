## 一、修复内容

### Layer 1：内置 Skill `reversible` 标记修复

**文件：** `host_brain/skills/builtin_registry.py`

**根因：** 7 个内置 skill 全部设置了 `reversible=True`，但它们的 handler 均返回不含 `manifest_ref` 的 dict。`SkillLoader`（`loader.py` 第 205–224 行）在 `reversible=True` 且 `manifest_ref` 为 `None` 时强制返回 `UNDO_REQUIRED`。

**修复：** 将全部 7 处 `reversible=True` 改为 `reversible=False`，并更新 docstring。

涉及的 skill（共 7 个）：
- `narrative_only`
- `memory_recall`
- `noop`
- `read_only_status`
- `emotion_query`
- `bond_query`
- `session_summary`

语义说明：这些 skill 均为只读 / 无副作用操作，没有任何可撤销的状态变更，`reversible=True` 是语义错误。

### Layer 2：`ToolCatalog` 启动时注册内置工具

**文件：** `host_brain/app/http_hooks.py`

**根因：** `get_tool_catalog()` 构造 `ToolCatalog()` 时不传任何参数，`_tools = {}`；`runtime_lifespan` 中也没有任何对 `catalog.register()` 的调用。

**修复：** 在 `runtime_lifespan` 中，在 `build_startup_report` 调用前新增内置工具注册块。注册逻辑：
1. 获取 `ToolCatalog`、`ToolBroker`、`SkillRegistry` 单例
2. 遍历 6 个内置 READ 工具定义
3. 检查 `SkillRegistry` 中对应 skill 是否存在，存在则注册 `ToolMeta` 到 `ToolCatalog`，并在 `ToolBroker` 中绑定 handler（代理到 skill handler）
4. 注册结果写入 `new_module_statuses["builtin_tools_catalog"]`

注册的 6 个工具：

| tool_id | side_effect_level | auth_level | domain_tags |
|---|---|---|---|
| `file_list` | READ | NONE | file |
| `file_read` | READ | NONE | file |
| `memory_search` | READ | NONE | memory |
| `system_info` | READ | NONE | system |
| `network_status` | READ | NONE | system |
| `web_search` | READ | NONE | web |

### Layer 3：MCP provider — 设计态 DEGRADED（不修复）

**结论：** 当前没有任何真实的 MCP provider 配置，`/health/mcp` 返回 `STARTUP_MCP_DEGRADED` 是正确的降级行为，不是代码 bug。封测口径调整为：**MCP 部分以"无 provider 时稳定降级，不卡死"作为通过标准**。
