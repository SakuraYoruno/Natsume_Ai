- T-NE01-WORKSPACE-LIFECYCLE-02：Internal clean/no-change path必须以真实TaskStore evidence触发accepted HEAD capture并推进`ACTIVE→ACCEPTED→PROMOTED`；启动期sealed checkpoint continuation与response-loss exact replay都不得重跑Agent。terminal worker只允许精确sealed abandon/cleanup。该正向路径不覆盖一般write、周期survivor continuation、crash-left unsealed partial cleanup、failure/cancel/budget claim closeout或general `settle_worker` crash bundle；OS/container/tenant与handle-level原子TOCTOU隔离也未提供。状态保持`PARTIAL_W2_NO_CHANGE_PROMOTION_WIRED / GENERAL_WRITE_INCOMPLETE`，不得写成Workspace Isolation完成。

### 本地交付元数据 Gate

- T-DELIVERY-METADATA-01：`origin/dev..HEAD` 的每个提交必须是单父中文 vertical slice，标题只允许 `重构/修复/功能/测试/文档/性能/安全/构建：中文结果`；merge commit、英文 merge 标题、字面量 `\\n` 与无中文结果均失败关闭。
- T-DELIVERY-METADATA-02：PR 标题必须包含中文；正文必须由真实 Markdown 文件传入，固定七个二级章节各出现一次且顺序不变。字面量 `\\n` 和未带 `INCOMPLETE/PARTIAL/未完成/不宣称` 等边界的整体 `PASS/DONE/闭环` 声明必须阻断。
- 当前远程 CI 只能记录 `NOT_RUN_ACCOUNT_QUOTA`；本地 Gate 通过不能替代 Actions 实际执行，也不能提升任何架构完成状态。

### NE-01 Universal Runtime 覆盖 Gate

- T-NE01-UGR-GATE-01：coverage manifest 必须精确包含 `chat/skill/plan/delegate/scheduler/internal/operator` 七条路线及完整控制集；缺任一路线、缺任一控制或 declared/derived 状态不一致均失败关闭。
- T-NE01-UGR-GATE-02：机器状态必须声明完整 lowercase Git SHA 与仓库实际连续 migration head；不存在、非当前 HEAD 祖先的提交或落后 migration head 均拒绝。
- T-NE01-UGR-GATE-03：`commit_bound_acceptance=PASS` 必须引用 JSON receipt，且 receipt 的 `commit_sha`、`migration_head` 与 route `PASS` 结果精确匹配；旧 GR-06 四路线 receipt 不具备当前资格。
