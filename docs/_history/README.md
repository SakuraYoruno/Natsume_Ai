# 历史文档归档

本目录保存已经退出当前 authority 的计划、审计、报告和固定证据。归档文件只说明其绑定日期、commit 和环境，不定义当前产品状态。

| 目录 | 内容 |
|---|---|
| `programs/` | 历史架构和长期演进程序 |
| `quality/` | 历史整改计划、审计和阶段基线 |
| `project/` | 已停用的协作说明和项目完成报告 |
| `releases/` | 已结束发布批次的计划与执行报告 |
| `testing/` | 体积较大的生成式测试快照 |
| `trace/` | 旧 Bug、投影和试运行追溯 |

当前入口始终从 [文档地图](../00_index/00_DOCMAP.md) 进入。历史文件中的 `PASS`、`DONE`、完成率和路线结论不会自动继承到当前版本。
