## F-21 Canon 热词与 Canon 审批

**判定：PASS（修复后）**

### 发现的 Bug 及修复

**Bug 1**: `wc-002-architecture-invariants.json` 存在 UTF-8 BOM（EF BB BF），导致 canon sync 失败
- **修复**：直接移除文件 BOM

**Bug 2**: `SQLiteLedger._write_lock` 使用 `threading.Lock()`，`ledger.transaction()` 持有锁后，内部调用 `log_canon_proposal` 等方法也尝试获取同一锁，导致死锁（approve 超时 60s+）
- **修复**：`sqlite_ledger.py` 第 77 行，将 `threading.Lock()` 改为 `threading.RLock()`

**Bug 3**: `canon_routes.py` `approve_proposal` 函数用 `with ledger.transaction():` 包裹 `approve_proposal_with_content()`，而后者内部的 `with self._conn:` 会自动提交，导致外层 transaction 的 COMMIT 找不到活跃事务，返回 500
- **修复**：移除 `canon_routes.py` 中 `approve_proposal` 的 `with ledger.transaction():` 包裹

| 测试项 | 结果 |
|---|---|
| create_proposal | 201 pending |
| approve_proposal | 200 APPLIED，耗时 0.03s |
| verify_approved | 200 status=APPLIED |
| rollback_proposal | 200 |
