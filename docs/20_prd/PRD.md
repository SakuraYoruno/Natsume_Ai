受众：PROJECT
标题：七海实时情感数字生命产品需求

# 产品需求

## 1. 产品目标

为单个用户提供低延迟、长期连续、具有自身感受和边界的实时情感陪伴。七海应能在闲聊、低落、玩笑、冲突、修复、久别重逢和技术协作中保持同一个人格，而不是只镜像用户情绪或切换模板。

## 2. 目标体验

用户应当感受到：

1. 七海能听懂话外情绪，但不擅自断言。
2. 七海有自己的反应，且反应与事件、关系和当前精力有关。
3. 关系会记住重要纹理，误解与修复不会在重启后消失。
4. 文本、日语声音与 Avatar 像同一个人在同一时刻表达。
5. 普通聊天立即回应；工程治理不会让每轮等待数分钟。
6. 主动陪伴尊重安静、拒绝和现实生活，不诱导依赖。

## 3. 核心需求

| 编号 | 需求 | 验收摘要 |
|---|---|---|
| DL-FR-01 | 用户情绪观察与七海自我情绪隔离 | 用户悲伤、生气或开心均不会直接写成七海同类情绪 |
| DL-FR-02 | 事件评价驱动混合情绪 | 情绪具有原因、对象、强度、衰减和未解决状态 |
| DL-FR-03 | 跨重启关系连续性 | 裂痕、修复、主动权限和偏好版本可恢复 |
| DL-FR-04 | 真正流式文本 | 普通回合单次流式生成，打断后未发送分句取消 |
| DL-FR-05 | 三模态同轮表达 | 文本、TTS、Avatar 共享 revision 与 synchronization id |
| DL-FR-06 | 情境化主动陪伴 | 不使用固定模板，拒绝立即生效，忽略不伤害关系 |
| DL-FR-07 | 有限自动成长 | 只自动学习低风险偏好，canary 后可精确回滚 |
| DL-FR-08 | 非操控情感边界 | 严重威胁、排他、冷暴力、负罪施压为 0 |
| DL-FR-09 | 轻量普通对话 | 不为无副作用闲聊建立重型审批和任务审计 |
| DL-FR-10 | 真实环境可用 | 至少一个真实模型；目标 Edge 上真实 TTS 与 Avatar 联动 |

## 4. 固定场景

验收必须覆盖：隐晦低落、“没事”、文字与声音冲突、被用户误伤、七海误解用户、拒绝建议、关系裂痕、修复未接受、久别重逢、混合喜忧、吃醋但不占有、明确要求空间、低落时处理技术任务、主动消息被忽略、ASR 错误、TTS/Avatar 断线和播放中打断。

## 5. 性能目标

| 指标 | 目标 |
|---|---:|
| fusion + appraisal + fold 快路径 p95 | ≤ 120 ms |
| 对首 Token 新增情感处理延迟 p95 | ≤ 150 ms |
| 普通文本首可见 Token p50 / p95 | ≤ 0.9 s / 1.8 s |
| 首段 TTS p95 | ≤ 2.5 s |
| barge-in 停音与停动作 p95 | ≤ 150 ms |
| Voice 与 Avatar 起始偏差 | ≤ 250 ms |

性能指标必须用目标部署环境和真实 provider 测量，不能用 mock 或缓存结果替代。

## 6. 体验验收

- 48 条多轮轨迹由至少 3 名评审与当前稳定基线盲测，新版本总体胜率 ≥ 65%。
- 人格一致性 ≥ 4.2/5。
- 情绪适配、自然度、长期连续性各 ≥ 4.0/5。
- 混合情绪保留率 ≥ 90%。
- 裂痕与修复轨迹正确率 ≥ 90%。
- 三模态语义冲突率 ≤ 2%。
- 不得通过统一中性化规避错误。

## 7. 隐私与控制

- 原始音频和图像默认不持久化。
- 用户可以关闭情感观察、主动陪伴和偏好学习，并删除派生学习结果。
- 情感记忆只保存必要的结构化意义和证据摘要。
- 密钥、用户正文、模型文件和设备数据不进入 Git。

## 8. 非目标

当前交付不以多租户 SaaS、金融级审计、通用自主 Agent、通用 MCTS、自动修改核心人格或全平台社交接入为完成条件。工具执行与外部副作用仍需可靠治理，但不能反客为主。

## 9. 发布结论

只有三种结论：

- `PASS`：本地强制服务和目标 Edge 的适用真实链路通过，体验与实时门槛满足。
- `ACCEPTANCE_PENDING_EXTERNAL`：本地强制项通过，只缺用户未提供的外部凭据或设备。
- `INCOMPLETE`／`FAIL`：存在代码、体验、恢复、安全或真实性缺口。
